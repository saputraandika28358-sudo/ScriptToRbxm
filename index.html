Cara pakai (untuk pemula)
5 langkah — bikin API key sampai dapat Model ID
▾
1
Buka Creator Hub Roblox
Login akun Roblox kamu, lalu buka create.roblox.com/dashboard/credentials — halaman resmi Roblox untuk bikin API key.
2
Klik "Create API Key"
Kasih nama bebas, misal ScriptToRbxm.
3
Atur Access Permissions
Di Select API System, cari assets, lalu centang Read dan Write.
4
Simpan & salin API key-nya
Roblox cuma nampilin key sekali — langsung copy & simpan aman.
5
Isi form di bawah & klik Publish
File bisa otomatis kekirim kalau kamu datang dari tab Convert/Build, atau upload manual di sini. Model ID hasil upload muncul dalam beberapa detik.
